# 森博嗣 各巻ガイド

森博嗣の全シリーズ（S&M / V / 四季 / G / X / XX / 百年 / W / WW / スカイ・クロラ / ヴォイド・シェイパ / 水柿 / Z / 短編集 / シリーズ外 / クリーム）の各巻概要と作者コメントをまとめた静的サイト。

- 外部依存なしの単一 HTML（`index.html`）
- シリーズタブ切替・あらすじ／作者コメント表示切替・ネタバレ表示トグル・ダークモード対応
- 作者コメントは浮遊工作室（公式サイト）から取得
- Vercel でホスティング

## 公開

`index.html` をそのまま配信する静的サイト。ビルド不要。

## データ生成

作者コメントの取得・生成に使った Python スクリプトは `scripts/` に記録。詳細は `scripts/README.md`。
